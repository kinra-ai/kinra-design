      States

      Every icon is drawn with the same four strokes, so any state can become any other in one continuous motion. Choose a state to watch the key change.

      How it behaves

      • Pinned to the cornerThe key is the composer’s lower-right square, flush with its edge and radius. The whole square answers a press.
      • Lit only when something can goThe first character lights the key from its corner with one quick blink. Clearing the draft lets it go dark again.
      • One motion between iconsSend, Stop, Queue, Run and Command share four strokes, so a change of meaning is a single movement rather than a swap.
      • Sending moves upThe colour lifts out of the key the way the message rises into the conversation, while the arrow folds into Stop.
      • A light only while work runsWhile Kin works or files arrive, a light runs around the key’s edge. When the turn finishes, it closes into a ring and fades.
      • The same meaning without motionWith reduced motion the icons change in place and the edge light holds still. The key’s name always says what a press will do.

      Bringing it to Space

      In kinra-space the key would replace .composer-action in Composer.svelte. It needs no new state: every state follows from values the composer already derives, and the native host contract keeps its send and turn fields as they are.

      State Shown when Name
      Rest Nothing to send Send message, unavailable
      Send canSend Send message
      Queue queueing Queue message
      Run shellLine Run in the workspace
      Command slashRows.length Run command
      Sending sending Sending…
      Stop active && connected && !observer Stop Kin
      Uploading uploading Unavailable; the status line says why
      Can’t send failed or !admitted Unavailable; the status line says why
      Watching observer Unavailable while watching
      Reconnecting reconnecting Unavailable; the draft is kept

      Three of Space’s current choices would change with it:

      • Stop leaves the error colour. It becomes a neutral key with a running light, since stopping Kin is not a failure.
      • The tools row grows from 36px to the key’s 48px, so the composer is 12px taller.
      • The light while files arrive shows that work is happening, not how much is left. Space has no upload progress to show today.
