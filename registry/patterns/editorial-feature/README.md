# Editorial feature

Status: candidate · Evidence: Kinra Site Writing

Use this pattern to feature one authored work inside an editorial index. The
folio is identity and atmosphere, not an implied step in a process.

Do not use it for every article in a list or for chronological position that
is already communicated by a date.

## Accessibility

- Mark the decorative folio `aria-hidden="true"`.
- Keep the title as a real heading and the destination as a descriptive link.
- Do not rely on the folio to identify the article.
