# Operations region

Status: candidate · Evidence: Depot and the inference gateway

Use this pattern for a bounded operational responsibility that needs an
explicit state, one small action group, and inspectable evidence. The region
header describes the job; it is not automatically numbered.

Do not use it as a decorative card grid or to hide a multi-step workflow that
needs its own route and navigation.

## Accessibility

- Keep state in visible text; colour is supplementary.
- Give the table a caption and correctly scoped headers.
- Keep actions after the heading in source order and use descriptive labels.
- If rows become interactive, use real links or buttons rather than click
  handlers on table rows.
