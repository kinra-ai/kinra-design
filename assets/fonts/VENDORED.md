# Vendored fonts: Kinra Type

These files are built and released by Kinra Type. Update them together from
an immutable Type release; the drawing sources and generator stay upstream.

- Source: `kinra-ai/kinra-type`.
- Release: `v0.2.1` (2026-11-14), adopted on Blake’s authorization.
- Source commit: `fe38f4d6b72afccacff1d94784499d4e7da74474`.
- License: SIL Open Font License 1.1, no Reserved Font Names; retain `OFL.txt`.
- Styles: Mono upright, Sans upright and italic, Serif upright and italic.
- Weight axis: 300–800; family names and asset paths are unchanged.

The release refines every ampersand and Sans text spacing. Sans sample words
average 4.0% narrower, so consuming products should check line wrapping.
